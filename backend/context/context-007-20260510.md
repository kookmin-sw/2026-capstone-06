# context-007-20260510: nGrinder 부하 테스트 환경 추가

## Status
- [x] Completed

## Context
시스템 부하 테스트를 위해 nGrinder를 Docker 환경에서 구동할 수 있도록 설정함.

## Decision
- `docker-compose.yml`에 `ngrinder-controller`와 `ngrinder-agent` 서비스를 추가함.
- Controller Web UI 포트를 `8090`으로 할당하여 기존 서비스와 충돌을 방지함.
- `ngrinder_controller_data` 볼륨을 추가하여 설정 및 테스트 스크립트가 유지되도록 함.

## Consequences
- `docker-compose up -d` 실행 시 nGrinder 환경이 자동으로 구성됨.
- `http://localhost:8090`을 통해 nGrinder 관리 콘솔에 접속 가능.
- 기본 로그인 정보: `admin` / `admin`
