# context-003-20260510: JWT Security 기능 보완

## Status
- [x] Completed

## Context
기존 JWT 기반 인증 시스템에서 발생한 기능 누락(웹 로그인 시 JWT 미반환, 리프레시 토큰 미사용 등)을 해결하여 보안과 사용성을 강화함.

## Decision
- `User` 엔티티에 `refreshToken` 필드 추가.
- `AuthService.loginWeb` 및 `loginApp` 모두에서 Access/Refresh Token을 생성, 반환하도록 통일.
- `/member/refresh` 엔드포인트 신설을 통한 Access Token 재발급 기능 구현.
- `SecurityConfig`에 `/member/refresh` 경로 권한 허용 추가.

## Consequences
- 클라이언트(웹/앱)는 Access Token 만료 시 재로그인 없이 Refresh Token으로 인증 유지가 가능해짐.
- 웹 기반 로그인 클라이언트도 이제 JWT 토큰을 기반으로 STATELESS API 통신이 가능함.
