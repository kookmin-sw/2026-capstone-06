# context-002-20260510: Swagger(SpringDoc) 도입

## Status
- [x] Completed

## Context
API 명세의 시각화와 테스트 편의성을 위해 Swagger(SpringDoc) 라이브러리를 프로젝트에 추가함.

## Decision
- `springdoc-openapi-starter-webmvc-ui:2.3.0` 라이브러리 도입.
- `SecurityConfig`를 수정하여 `/v3/api-docs/**`, `/swagger-ui/**`, `/swagger-ui.html` 경로를 인증 없이 허용.

## Consequences
- `/api/swagger-ui/index.html`을 통해 API 문서를 확인하고 테스트할 수 있음.
- JWT 인증이 필요한 API의 경우 Swagger UI에서 Authorize 설정을 통해 테스트 가능.
