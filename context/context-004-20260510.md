# context-004-20260510: Swagger JWT 인증 설정 추가

## Status
- [x] Completed

## Context
Swagger UI에서 JWT 인증이 필요한 API를 테스트하기 위해 Authorize 버튼 및 Bearer 인증 스키마를 추가함.

## Decision
- `SwaggerConfig.java`를 생성하여 OpenAPI 빈을 정의.
- `SecurityScheme`을 통해 Bearer JWT 방식을 설정.
- 모든 API 요청에 전역적으로 보안 요구 사항(Security Requirement)을 적용.

## Consequences
- Swagger UI 우측 상단에 'Authorize' 버튼이 활성화됨.
- 로그인 API에서 발급받은 `accessToken`을 입력하면 이후 요청 시 헤더에 `Authorization: Bearer <token>`이 자동으로 포함됨.
